# 계약서 돋보기 / Contract Lens

동아AI랩 3기 3차 프로젝트 **V1-2 트랙**. 공익 목적.

계약서·약관을 넣으면 **판정하지 않고**, 해당 조항과 관련 법 조문을 나란히 놓아
일반인이 스스로 판단할 근거를 만들어 준다.

## 무엇을 하고 무엇을 하지 않는가

**한다**

- 계약서 조항을 「약관의 규제에 관한 법률」이 열거한 불공정 유형과 대조
- 해당 조문 원문을 그대로 인용해 나란히 표시
- 표준계약서에 있는데 이 계약서에 없는 조항 표시
- 관련 판례 검색 결과를 링크와 함께 제시

**하지 않는다**

- "이 조항은 무효입니다" 같은 **법적 판단**
- 개별 사실관계 파악 · 법규 검토 · 법적 추론
- 변호사 연결이나 유료 검토 알선

이 경계는 취향이 아니라 **법적 요건**이다. 2026년 대법원 판결(3부, 주심 오석준)은
법률사무에 해당하려면 **구체적·개별적 사실관계 파악 + 적용 법규 검토 + 법적 추론·평가**가
필요하다고 봤고, *"이용자가 공란을 채우면 수정 없이 그대로 문서에 반영되는 형태"* 는
법률사무가 아니라고 판단했다. **판정을 하는 순간 위법 영역으로 들어간다.**

## 왜 이 구조가 정확한가

법률이 직접 유형을 열거한다. 「약관의 규제에 관한 법률」 제7조~제14조가 불공정 조항 유형을
구체적으로 적고 각각 "무효로 한다"고 명시한다.

```
제7조(면책조항의 금지) 1호
  사업자, 이행 보조자 또는 피고용자의 고의 또는 중대한 과실로 인한
  법률상의 책임을 배제하는 조항
제9조(계약의 해제·해지) 1호
  법률에 따른 고객의 해제권 또는 해지권을 배제하거나 그 행사를 제한하는 조항
제14조(소송 제기의 금지 등) 1호
  고객에게 부당하게 불리한 소송 제기 금지 조항 또는 재판관할의 합의 조항
```

그래서 **AI는 판정하지 않고 매칭만 한다.** "이 조항이 법 제몇조 몇호 유형과 형태가 같은가"를
분류하고, 답은 조문에서 그대로 옮긴다. 매칭이 애매하면 후보를 보여주고 사용자가 고른다.

**틀릴 여지가 매칭 한 곳에만 있고, 그 정확도는 계약서 표본으로 측정된다.**

## 데이터 (2026-08-23 실측)

| 소스 | 상태 |
|---|---|
| 국가법령정보 **법령 본문** API | **동작.** 약관규제법 49조문 → 불공정 유형 28개 구조화 완료 |
| 국가법령정보 **판례** API | **동작** (본인 `OC` 필요). 463건 수집 완료 |
| 공정위 표준약관 77개 | 미확인 |

**`JO` 참조조문 필터는 조문 번호를 신뢰할 수 없다.** `JO=제7조`로 229건이 나오지만
그 판례들의 실제 참조조문에는 제7조가 없다. 수집만 `JO`로 넓게 하고,
조문별 색인은 본문 참조조문을 직접 파싱해서 만든다. 상세는 `docs/api-notes.md`.

조문별 판례 수 (본문 참조조문 기준, 463건 중 410건에서 약관법 조문 검출):

```
제3조(명시·설명의무) 106   제5조(해석) 108   제6조(일반원칙) 138
제7조(면책조항)       19   제9조(해제·해지) 18   나머지 1~3건
```

**제7~14조의 구체적 유형은 판례가 거의 없다.** 실무에서 다투는 것은 제3·5·6조다.
조문 대조가 주축이고, 판례는 있으면 붙이고 없으면 "관련 판례 없음"으로 둔다.
