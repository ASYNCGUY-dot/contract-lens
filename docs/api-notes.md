# 국가법령정보 공동활용 API 실측 노트

2026-08-23 직접 호출해 확인한 것만 적는다. 문서 인용이 아니라 실측값이다.
같은 것을 다시 찌르지 않기 위한 기록.

## 기본

```
목록: https://www.law.go.kr/DRF/lawSearch.do
본문: https://www.law.go.kr/DRF/lawService.do
공통: OC=<이메일 아이디 앞부분>, type=JSON|XML|HTML
```

**`OC`가 전부를 가른다.** `OC=test`(데모)는 법령만 되고 판례는 국세 판례 목록만 보이며
본문 조회가 `"일치하는 판례가 없습니다"`로 막힌다. 본인 `OC`를 쓰면 대법원 판례와
본문이 전부 열린다. `.env`의 `LAW_OC`에 둔다.

## 법령 (target=law)

```
GET lawSearch.do?target=law&query=약관의 규제에 관한 법률   → 법령일련번호(MST)
GET lawService.do?target=law&MST=260021                    → 본문
```

응답 구조: `법령 → {개정문, 법령키, 기본정보, 부칙, 조문, 제개정이유}`
조문은 `조문 → 조문단위[]`, 각 단위에 `조문번호 / 조문제목 / 조문내용 / 항[] → 호[]`.

약관의 규제에 관한 법률(MST=260021, 시행 20240807) **49개 조문** 확인.
제2장 불공정약관조항이 제6조~제14조이고, 각 조가 유형을 호 단위로 열거하며
"무효로 한다"고 명시한다. **이것이 이 프로젝트의 매칭 대상 목록이다.**

## 판례 (target=prec)

### 검색 파라미터 — 실측

| 파라미터 | 효과 | 실측 |
|---|---|---|
| `query` (기본) | **사건명 검색**. 본문은 안 봄 | `면책조항` → 0건 |
| `search=2` | **본문검색** | `면책조항` → **825건** |
| `JO` | **참조조문 필터. 조문 단위까지 됨** | 아래 표 |
| `curt` | 법원 필터 | `query=약관&curt=대법원` → 11건 |
| `prncYd` | 선고일자 범위 (`20200101~20261231`) | `query=약관` 조합 → 7건 |
| `display` | 최대 100 확인 | 100 정상 |
| `page` | 페이징 동작 확인 | page3까지 100건씩 정상 |

`query` 없이 호출하면 **전체 170,734건**.

### `JO` 참조조문 필터 (핵심)

```
JO=약관의 규제에 관한 법률          → 525건
JO=약관의 규제에 관한 법률 제6조    → 366건   (일반원칙)
JO=약관의 규제에 관한 법률 제7조    → 229건   (면책조항의 금지)
JO=약관의 규제에 관한 법률 제9조    → 196건   (계약의 해제·해지)
```

**조문 → 판례 역방향 연결을 API가 직접 지원한다.** 우리가 분류하는 게 아니라 조회 결과다.
`display=100` + `page`로 전건 수집 가능. page1은 대법원 100/100.

### 본문 조회

```
GET lawService.do?target=prec&ID=<판례일련번호>&type=JSON
```

실측 11,482자. 필드:

```
판시사항 · 참조판례 · 사건종류명 · 판결요지 · 참조조문 · 선고일자 · 법원명
사건명 · 판례내용 · 사건번호 · 사건종류코드 · 판례정보일련번호 · 선고 · 판결유형 · 법원종류코드
```

**`참조조문`이 구조화되어 있다.** 예:

```
[1] 소액사건심판법 제3조 제2호 / [2] 상법 제638조의3 제1항,
약관의 규제에 관한 법률 제3조 / [3] ...
```

대법원 판례 6건을 열어본 결과 5건에서 약관규제법 조문이 정규식으로 추출됐다:
`약관의 규제에 관한 법률 제6조 제1항`, `제5조 제1항`, `제2조 제1호` 등.

## 이 프로젝트에서 쓰는 방식

1. 약관규제법 제6~14조를 호 단위로 구조화 → **매칭 대상 목록**
2. 계약서 조항을 그 목록과 매칭 (AI는 여기까지만)
3. 매칭된 조문의 판례를 `JO` 필터로 조회 → **근거로 나란히 제시**
4. 조문 원문과 판례 링크를 그대로 인용. **판정 문구는 쓰지 않는다.**

3번이 조회 결과라 우리가 지어낼 여지가 없다. 2번의 매칭 정확도만 측정하면 된다.

## 아직 확인 안 한 것

- 공정위 표준약관 77개 / 표준하도급계약서 13개 업종 / 가맹 13개 업종의 기계 수집 가능 여부
- `JO` 필터가 "제7조 제1호" 같은 호 단위까지 되는지 (조 단위는 확인됨)
- 일일 호출 한도
