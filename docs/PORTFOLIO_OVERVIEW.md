# 계약서 돋보기 | 포트폴리오 안내

## 해결하려는 문제
계약서의 조항을 읽는 사람이 어떤 법 조문을 함께 확인해야 하는지 찾기 어렵습니다.
계약 조항을 분리하고 약관규제법의 관련 조문을 최대 세 개까지 나란히 제시합니다.

## 구현과 역할
개인 프로젝트로 데이터 수집·조항 분리·임베딩 매칭·API·웹 화면을 구성했습니다.
Python, FastAPI, React, ONNX를 사용하며, 사진의 문자는 tesseract.js로 브라우저 안에서 읽고 사람이 확인한 뒤 분석합니다.
LLM 구조 추출은 선택 기능이고, 핵심 조문 매칭은 로컬 임베딩을 사용합니다.

## 확인된 한계
README에 기록된 실제 사설 약관 평가에서 1순위 정답은 41.7%, 3개 안에 정답은 75.0%입니다.
이 수치는 작은 기록 표본의 결과이며 이번 포트폴리오 정리에서 재측정하지 않았습니다.
OCR 수치도 실제 종이 촬영 검증이 아니라 합성 이미지 실험입니다.
조문 후보는 법률적 결론이나 무효 판정을 의미하지 않습니다.
